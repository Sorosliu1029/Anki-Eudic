1. 生词本API

1.1. 获取所有生词本

  1. 接口说明：

    • 请求方式：GET
    • 请求地址：https://api.frdic.com/api/open/v1/studylist/category
    • 本接口用于获取生词本信息
    • 生词本的ID是唯一标识，用于调用其他接口

  2. 协议须知：

    规则 描述
    传输方式 HTTPS
    请求方式 GET
    字符编码 UTF-8
    响应格式 JSON

  3. 接口调用参数：

    字段名 数据类型 参数类型 含义 必填 备注
    language string query 语言 True en/fr/de/es

  4. 输出结果：

    字段名 类型 含义 备注
    data Array 生词本信息 请求成功时存在
    message text 提示信息

    *data 生词本信息：

    字段名 类型 含义 备注
    id text 生词本ID
    language text 语言
    name text 生词本名称

  5. 示例：

    • Requset Method: GET

    • Request URL：https://api.frdic.com/api/open/v1/studylist/category?language=en

    • Response Code：200

    • Response Body：

        {
  "data": [
      {
      "id": "0",
      "language": "en",
      "name": "我的生词本"
      },
      {
      "id": "132303016416635230",
      "language": "en",
      "name": "nanana3"
      },
      {
      "id": "132303016647118400",
      "language": "en",
      "name": "新的名称"
      }
  ],
  "message": ""
  }

  6. 生成接口请求代码(python-request)：

     import requests

 url = "https://api.frdic.com/api/open/v1/studylist/category?language=en"

 headers = {
 'User-Agent': 'Mozilla/5.0',
 'Authorization': 'NIS xxxx'
 }

 response = requests.request("GET", url, headers=headers)
 print(response.text)

1.8. 新增生词本中的一个单词

  1. 接口说明：

    • 请求方式：POST
    • 请求地址：https://api.frdic.com/api/open/v1/studylist/word
    • 本接口用于往生词本里添加单词

  2. 协议须知：

    规则 描述
    传输方式 HTTPS
    请求方式 POST
    字符编码 UTF-8
    响应格式 JSON

  3. 接口调用参数：

    字段名 数据类型 参数类型 含义 必填 备注
    value object body 生词信息 True Content-Type: application/json

    *value 生词本信息：

    字段名 数据类型 含义 必填 备注
    language text 语言 True en/fr/de/es
    word text 单词 True
    star text 等级 False
    context_line text 语境 False
    category_ids text 分组列表 False 不设置则加到默认分组

  4. 输出结果：

    字段名 类型 含义 备注
    message text 提示信息

  5. 示例：

    • Requset Method: POST

    • Request URL：https://api.frdic.com/api/open/v1/studylist/word

    • Request Body：

        {
      "language": "en",
      "word": "hello",
      "star": 2,
      "context_line": "hello, how are you?",
      "category_ids": [0]
  }

    • Response Code：201

    • Response Body：

        {
  "message": "单词添加成功"
  }

  6. 生成接口请求代码(python-request)：

     import http.client
 import json

 conn = http.client.HTTPSConnection("api.frdic.com")
 payload = json.dumps({
 "language": "en",
 "word": "hello",
 "star": 2,
 "context_line": "hello, how are you?",
 "category_ids": [0]
 })
 headers = {
     'User-Agent': 'Mozilla/5.0',
     'Authorization': 'NIS xxxx',
     'Content-Type': 'application/json'
 }

 conn.request("POST", "/api/open/v1/studylist/word/", payload, headers)
 res = conn.getresponse()
 data = res.read()
 print(data.decode("utf-8"))

1.11. 查询用户语料列表

  1. 接口说明：

    • 请求方式：GET
    • 请求地址：https://api.frdic.com/api/open/v1/studylist/vocab_entries
    • 返回当前用户的语料列表。
    • 支持按最近 N 天和是否已收藏到生词本（study_list.rating > 0）筛选。

  2. 协议须知：

    规则 描述
    传输方式 HTTPS
    请求方式 GET
    字符编码 UTF-8
    响应格式 JSON

  3. 接口调用参数：

    字段名 数据类型 参数类型 含义 必填 备注
    language string query 语言 True en/fr/de/es
    recent_days integer query 最近 N 天 False <= 0 表示不筛选
    is_favorited bool query 是否已收藏到生词本 False true 只看已收藏，false 只看未收藏
    page integer query 页码 False 从 0 开始，最小 0，最大 50
    page_size integer query 每页数量 False 默认 100，最大 100

  4. 输出结果：

    字段名 类型 含义 备注
    data Array 语料列表 成功时返回
    message text 提示信息

    data 字段说明：

    字段名 类型 含义 备注
    word string 单词
    exp string 释义
    add_time string 添加时间
    rating int 生词本评级 > 0 表示已收藏
    contexts Array 语境列表 可能为空

    contexts 字段说明：

    字段名 类型 含义 备注
    src string 原文语境
    trans string 译文语境
    word_in_context string 语境中的词形

  5. 调用示例：

    • 请求方式：GET

    • 请求地址：https://api.frdic.com/api/open/v1/studylist/vocab_entries?language=en&recent_days=30&is_favorited=true&page=0&page_size=2

    • 响应状态码：200

    • 响应内容：

        {
    "data": [
      {
        "word": "action",
        "exp": "n. action; activity; function; plot; combat",
        "add_time": "2025-03-01T08:30:00Z",
        "rating": 2,
        "contexts": [
          {
            "src": "He took immediate action to solve the problem.",
            "trans": "He solved it right away.",
            "word_in_context": "action"
          }
        ]

    1.14. 解析文章生成语料提示

    1. 接口说明：

      • 请求方式：POST
      • 请求地址：https://api.frdic.com/api/open/v1/studylist/vocab_hints?language=en
      • 解析传入的文章文本，返回可同步到用户语料库的重点单词、词组和来源上下文，不直接写库。
      • 同一用户 30 分钟最多请求 5 次，超过后返回 429。

    2. 协议须知：

      规则 描述
      传输方式 HTTPS
      请求方式 POST
      字符编码 UTF-8
      响应格式 JSON

    3. 接口调用参数：

      字段名 数据类型 参数类型 含义 必填 备注
      language string query 语言 True en/fr/de/es
